# SIMDEC 3 — Тренажер управлінських рішень

Кафедра економіки та публічного управління ННІПСМ ДонДУВС.

Третя версія працює без React і без збирання: GitHub Pages показує файли так, як вони лежать у репозиторії.

## Що де лежить

| Файл | Призначення |
|---|---|
| `index.html` | тренажер для здобувачів |
| `editor.html` | редактор кейсів (для викладачів) |
| `data/simdec-data.js` | **увесь зміст**: налаштування, описи моделей, етапи, кейси |
| `assets/` | оформлення, скрипти, зображення |

Код у `assets/js` під час роботи з кейсами змінювати не потрібно.

## Як додати або виправити кейс

1. Відкрийте `editor.html` (на сайті: `…/editor.html`).
2. Ліворуч оберіть кейс або натисніть «+ Новий кейс» під потрібною моделлю.
3. Заповніть назву, ввідну, питання на кожному етапі та варіанти відповідей. Позначте кружечком правильний варіант, до кожного варіанта напишіть пояснення.
4. «Переглянути» відкриває тренажер з вашою чернеткою (результати в цьому режимі не надсилаються).
5. «Завантажити simdec-data.js» → на GitHub відкрийте папку `data` → **Add file → Upload files** → перетягніть файл → **Commit changes**. За 1–2 хвилини зміни з’являться на сайті.

Чернетка зберігається в браузері автоматично, тож редагування можна переривати.
Кнопка «Відкрити файл…» також приймає окремі кейси формату SIMDEC 2 (`pdca4.json` тощо).

## Результати

Після завершення кейсу здобувач натискає «Надіслати результат викладачеві». У Google Apps Script надсилаються ті самі поля, що й у версії 2: `name`, `date`, `result`, `percent`, `model` (наприклад, `OODA (Кейс 3)`), тому таблиця працює без змін. Адресу скрипта можна змінити в редакторі → «Загальні налаштування».
